## 技能概述

腾讯文档 MCP（个人版 `docs.qq.com`）的**已验证用法与实测踩坑**，覆盖智能表格（smartsheet）与在线表格（sheet）。

核心结论：

- 需要写文本就必须用**在线表格** —— 智能表格的文本 / 单选字段**写不进去**（试过 6 种变体全失败）
- 明文公式会被 **WAF 拦（HTTP 501 / waf-captcha）**，必须改用 `value_base64`
- 命令行传参过长会撞 **`WinError 206`**，改用 `import` 方式调 `call_tool`
- 清空范围会**连公式一起删**，且超出新表默认 200×31 会报 `code 608698`
- 公式拼接**少一个右括号会静默失败** —— Excel 里「文本 >= 数字」恒为真，下游 IF 走错分支
- 写完公式**必须全表扫描验收**（有以 `=` 开头的单元格即为解析失败）
